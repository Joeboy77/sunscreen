# Sunscreen Projects

This repository contains two ambitious projects:

## 1. Sunscreen Programming Language
A fast, simple, and friendly programming language built from scratch.

### Goals:
- Simple and intuitive syntax
- Fast execution
- Beginner-friendly
- Extensible design

### Development Phases:
- [x] Project setup
- [ ] Phase 1: Basic interpreter (numbers, strings, variables, print)
- [ ] Phase 2: Control flow (if/else, loops, functions)
- [ ] Phase 3: Advanced features (arrays, objects, file I/O)
- [ ] Phase 4: Optimization and polish

## 2. Sunscreen Web Browser
A robust web browser built from scratch.

### Goals:
- Fast and efficient
- Secure browsing
- Modern web standards support
- Clean, intuitive interface

### Development Phases:
- [ ] Phase 1: Basic browser shell and navigation
- [ ] Phase 2: Tab management and rendering
- [ ] Phase 3: Security features and extensions
- [ ] Phase 4: Advanced features and optimization
